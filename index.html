Agente Conversacional con IA y RAG usando Semantic Kernel + Ollama (.NET 10)

Llama 3, Ollama, RAG, Semantic Kernel, ASP.NET Core 10, Razor

Monolito modular con una vista en Razor que se conecta a la aplicación y desde donde se consulta al agente y se suben documentos. El modelo Llama 3 corre localmente con Ollama. El agente responde de dos maneras: solo con el modelo o con RAG, usando los documentos cargados como contexto. Los documentos se guardan en memoria y Semantic Kernel crea el agente y el flujo de RAG. Sirve para comparar la calidad de las respuestas y ver cuándo el contexto propio marca la diferencia.

AWS Lambda, API Gateway, DynamoDB, .NET MAUI, Blazor, Firebase Hosting

Sistema que obtiene la ubicación solo cuando se solicita. El backend es serverless: funciones AWS Lambda expuestas por API Gateway, con las coordenadas guardadas en DynamoDB. Plantilla Clean Architecture con CQRS en .NET

.NET 10, C#, Clean Architecture, CQRS, MediatR, Entity Framework Core, SQL Server, Swagger, OpenTelemetry, Docker Compose

Plantilla base para construir APIs empresariales en .NET 10 con Clean Architecture, CQRS con MediatR y Entity Framework Core, organizada en cuatro proyectos: dominio, aplicación, infraestructura y presentación. Incluye SQL Server con migraciones iniciales, manejo centralizado de excepciones, queries y comandos de referencia, Swagger para pruebas interactivas y OpenTelemetry para observabilidad. Con Docker Compose levanta la API y la base de datos con un solo comando. El código se publica con fines educativos y de demostración: su uso requiere autorización del autor.
