## Proyectos destacados

### 1. Agente Conversacional con IA y RAG

Agente conversacional que utiliza Llama 3 mediante Ollama y Semantic Kernel. Permite consultar directamente al modelo o utilizar documentos cargados como contexto mediante RAG.

**Tecnologías:** .NET 10, ASP.NET Core, C#, Razor, Llama 3, Ollama, Semantic Kernel y RAG.

- [Código fuente en GitHub](https://github.com/javier-diaz-tech/Conversational-AI-Agent-RAG)
- [Video de demostración](https://youtu.be/c_vG2MsYkoI)

### 2. RutaSegura: geolocalización bajo demanda

Sistema de geolocalización que obtiene la ubicación únicamente cuando se solicita. Incluye backend serverless, aplicación móvil y aplicación web.

**Tecnologías:** .NET MAUI, Blazor, AWS Lambda, API Gateway, DynamoDB y Firebase Hosting.

- [Código y arquitectura en GitHub](https://github.com/javier-diaz-tech/AppSeguridad)
- [Video de demostración](https://youtube.com/shorts/sjHSd40jtlM)
- [Solicitar acceso de prueba](mailto:javier.diaz.tech@gmail.com?subject=Acceso%20de%20prueba%20a%20RutaSegura)

### 3. Plantilla Clean Architecture con CQRS en .NET

Plantilla base para desarrollar APIs empresariales con Clean Architecture, CQRS y MediatR. Organizada en cuatro proyectos: dominio, aplicación, infraestructura y presentación.

Incluye migraciones, manejo centralizado de excepciones, comandos y consultas de referencia, Swagger, OpenTelemetry y Docker Compose.

**Tecnologías:** .NET 10, C#, Clean Architecture, CQRS, MediatR, Entity Framework Core, SQL Server, Swagger, OpenTelemetry y Docker Compose.

- [Código fuente en GitHub](https://github.com/javier-diaz-tech/clean-architecture-cqrs-template-dotnet)

El código se publica con fines educativos y de demostración; su uso requiere autorización del autor.

## Caso de estudio: arquitectura de banca por internet

Propuesta técnica de arquitectura para un sistema de banca por internet con consulta de movimientos y transferencias, integrado con un core bancario legado.

Documentado mediante diagramas C4 y nueve decisiones de arquitectura (ADR).

**Aspectos considerados:**

- API Gateway y BFF por canal.
- Aislamiento del core bancario.
- Idempotencia y conciliación.
- Kafka y Avro.
- Auditoría mediante patrón Outbox.
- Kubernetes y recuperación ante desastres.

[Consultar el caso de estudio en GitHub](https://github.com/javier-diaz-tech/ArquitecturaSoluciones)
